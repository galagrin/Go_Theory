# Массивы и Слайсы в Go (Arrays & Slices)

Хотя внешне синтаксис массивов и слайсов похож, под капотом это принципиально разные сущности: **массив — это монолитный кусок памяти**, а **слайс — это легкий дескриптор (указатель) поверх массива**.

---

## 1. Массивы (Arrays)

**Массив** в Go — это последовательность элементов **фиксированной длины**, определяемой на этапе компиляции.

```go
var a [5]int           // Массив из 5 нулей: [0 0 0 0 0]
b := [3]string{"a", "b", "c"}
c := [...]int{1, 2, 3} // Длина вычисляется автоматически (...)
```

### Главные особенности массивов:

**Размер** — часть типа: [3]int и [5]int — это разные типы данных. Ты не можешь передать [5]int в функцию, которая ожидает [3]int.

**Передача по значению (Копирование):** При присвоении массива новой переменной или передаче в функцию весь массив копируется целиком (байт в байт).

```go
arr1 := [3]int{1, 2, 3}
arr2 := arr1 // Полная копия данных!
arr2[0] = 99

fmt.Println(arr1) // [1 2 3]  — исходный массив НЕ изменился
fmt.Println(arr2) // [99 2 3]
```

## 2. Слайсы (Slices)

Слайс (срез) — это динамическая и гибкая "обертка" над массивом.

```go
var s []int              // nil-слайс (len=0, cap=0, ptr=nil)
s2 := []int{1, 2, 3}     // Слайс с инициализацией
s3 := make([]int, 3, 5)  // len=3, cap=5
```

#### Что находится внутри слайса? (reflect.SliceHeader)

На уровне Runtime слайс — это маленькая структура размером всего 24 байта (на 64-битных системах):

```go
type SliceHeader struct {
    Data uintptr // 8 байт: указатель на первый элемент базового массива
    Len  int     // 8 байт: текущая длина слайса (сколько элементов доступно)
    Cap  int     // 8 байт: емкость (сколько всего элементов вмещает выделенный массив)
}
```

Len (Length): Количество элементов, доступных в слайсе прямо сейчас (len(s)).

Cap (Capacity): Максимальное количество элементов от начала слайса до конца подлежащего массива (cap(s)).

## 3. Слайсинг (Slicing) и Общий Подлежащий Массив

При взятии среза от массива или другого слайса (s[low:high]) новый массив не выделяется. Новый слайс указывает на тот же самый подлежащий массив!

```go
base := [5]int{10, 20, 30, 40, 50}

s1 := base[1:4] // Элементы с индекса 1 по 3: [20, 30, 40]
// s1.Len = 3
// s1.Cap = 4 (от индекса 1 до конца массива)

s1[0] = 999 // Изменяем s1...

fmt.Println(base) // [10, 999, 30, 40, 50] — base ТОЖЕ ИЗМЕНИЛСЯ!
```

## 4. Как работает append() и Аллокации Памяти

Функция append добавляет элементы в слайс.

Если Len < Cap: Элемент просто записывается в базовый массив по индексу Len, и Len увеличивается на 1. Аллокации нет.

Если Len == Cap (Массив переполнен):

-   Go выделяет новый, более крупный массив в куче.

-   Копирует старые элементы в новый массив.

-   Добавляет новый элемент.

-   Возвращает новый слайс, указывающий на новый массив.

Как растет Cap при реаллокации?

-   В Go < 1.18: при cap < 1024 емкость удваивалась (x2), затем росла на 25% (x1.25).

-   Начиная с Go 1.18+: формула стала более плавной. До cap = 256 емкость удваивается (x2), а дальше рост плавно замедляется к коэффициенту x1.25.

## 5. Грабли с append

### ⚠️ Опасность: "Разделение" базового массива

Если передать слайс в функцию и вызвать в ней append, поведение зависит от cap:

```Go

func mutate(s []int) {
    s = append(s, 42) // Если был запас cap, изменится исходный массив!
    s[0] = 999        // Если произошла реаллокация, s начнет указывать на новый массив
}
```

### ⚠️ Утечки памяти при слайсинге (Memory Leaks)

Если есть огромный массив (например, на 1 ГБ) и ты берешь маленький срез small := huge[0:2], весь 1 ГБ массива останется в памяти и не будет собран GC, так как на него ссылается small через указатель Data.

Решение: Копировать нужные данные через copy():

```Go

small := make([]byte, 2)
copy(small, huge[0:2]) // Теперь huge может быть утилизирован GC
```

## Сравнение: Массив vs Слайс

| Характеристика     | Массив ([N]T)                   | Слайс ([]T)                             |
| ------------------ | ------------------------------- | --------------------------------------- |
| Размер             | Зафиксирован при компиляции     | Динамический (растет через append)      |
| Память             | Непосредственно данные          | "Структура из 3 полей (Data, Len, Cap)" |
| Передача в функцию | Копирует весь массив            | Копирует только 24-байтовую структуру   |
| Сравнение (==)     | Можно сравнивать (arr1 == arr2) | Нельзя сравнивать (только s == nil)     |

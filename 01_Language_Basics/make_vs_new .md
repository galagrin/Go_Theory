# make vs new в Go

Главное отличие кратко:

-   **`new(T)`** выделяет зануленную память под тип `T` и возвращает **указатель `*T`**. Работает с любыми типами.
-   **`make(T, args)`** инициализирует внутренние структуры данных и возвращает **готовое значение типа `T`** (не указатель!). Работает **только** со слайсами (`slice`), картами (`map`) и каналами (`chan`).

---

## 1. Функция `new(T)`

Функция `new` — это встроенная функция, которая:

1. Выделяет память под значение типа `T`.
2. Заполняет эту память **нулевым значением** (zero value) для этого типа (`0`, `""`, `false`, `nil`).
3. Возвращает указатель на эту память (`*T`).

```go
type User struct {
    Name string
    Age  int
}

// 1. new со структурой
u := new(User) // Тип u: *User
// u указывает на User{Name: "", Age: 0}

// Эквивалентно через литерал:
u2 := &User{} // Абсолютно идентично new(User)

// 2. new с базовыми типами
p := new(int) // Тип p: *int (указывает на 0)
*p = 42
```

## 2. Функция make(T, args)

Слайсы, карты и каналы — это не просто сырые байты памяти. Это составные типы с внутренними метаданными (указатели на базовые массивы, хеш-таблицы, буферы и очереди горутин).

make создаёт и полноценно инициализирует эти внутренние структуры runtime, подготавливая объект к немедленному использованию.

```go
// 1. Slice: создается SliceHeader + выделяется базовый массив
s := make([]int, 3, 5) // len=3, cap=5, тип: []int (НЕ указатель!)

// 2. Map: создается структура hchan/hmap, выделяются бакеты
m := make(map[string]int) // готовая к записи карта, тип: map[string]int

// 3. Channel: создается структура hchan, выделяется кольцевой буфер
ch := make(chan int, 10) // буферизованный канал, тип: chan int
```

## 3. Что произойдет, если применить new к слайсу или карте?

Если вызвать new для слайса, карты или канала, Go выделит память под саму зануленную верхнеуровневую структуру и вернет указатель на нее. Внутренности объекта останутся nil!

### Пример 1: new для слайса

```go
sPtr := new([]int) // Тип: *[]int
// *sPtr это SliceHeader{Data: nil, Len: 0, Cap: 0}

// Использовать *sPtr можно только с append:
*sPtr = append(*sPtr, 1)

// Но попытка обратиться по индексу вызовет panic!
// (*sPtr)[0] = 100 // panic: runtime error: index out of range
```

### Пример 2: new для карты (map) — Опасно! 💥

```go
mPtr := new(map[string]int) // Тип: *map[string]int
// *mPtr имеет значение nil!

// Попытка записи в nil-карту вызовет ПАНИКУ:
(*mPtr)["key"] = 10 // panic: assignment to entry in nil map
```

| Характеристика | new(T)                                       | "make(T, args)"                             |
| -------------- | -------------------------------------------- | ------------------------------------------- |
| Применимость   | "Любые типы (структуры, int, string и т.д.)" | "Только slice, map, chan"                   |
| Что возвращает | Указатель на тип (\*T)                       | Сам тип / значение (T)                      |
| Память         | Зануляет память (zero value)                 | Инициализирует внутренние структуры runtime |
| Аналог в Go    | &T{} (для структур)                          | "Литералы []T{}, map[K]V{}"                 |

## 💡 Практический совет для чистой разработки

В реальном Go-коде функция new() используется крайне редко. Для создания структур практически всегда используют краткий и наглядный синтаксис структурного литерала:

```go
// Вместо этого (неидиоматично):
u := new(User)
u.Name = "Alice"

// Пишут вот так (идиоматично):
u := &User{
    Name: "Alice",
}
```

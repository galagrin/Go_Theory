# 📌 sync.Once: Однократное выполнение

`sync.Once` гарантирует, что переданная функция выполнится **ровно один раз** за всё время жизни программы, сколько бы горутин параллельно ни вызывали метод `Do()`.

Используется для паттернов **Singleton**, инициализации подключений к БД, загрузки конфигов или тяжелых шаблонов.

---

## Пример использования

```go
package main

import (
    "fmt"
    "sync"
)

type Config struct {
    DBUrl string
}

var (
    instance *Config
    once     sync.Once
)

func GetConfig() *Config {
    once.Do(func() {
        fmt.Println("Инициализация конфига (тяжелая операция)...")
        instance = &Config{DBUrl: "postgres://localhost:5432"}
    })
    return instance
}
```

### Как это устроено внутри?

Под капотом `sync.Once` содержит атомарный флаг и мьютекс (runtime/once.go):

```go
type Once struct {
    done uint32 // Флаг: 0 - не выполнялось, 1 - выполнено
    m    Mutex
}
```

1. Fast Path (Быстрый путь):

    При вызове Do() сначала атомарно проверяется флаг done (atomic.LoadUint32). Если равен 1, функция мгновенно возвращает управление без захвата мьютекса.

2. Slow Path (Медленный путь):

    Если done == 0, захватывается m.Lock(), выполняется функция, затем флаг done атомарно переводится в 1 (atomic.StoreUint32).

## ⚠️ Важный нюанс

Если функция внутри once.Do(f) сгенерирует panic, sync.Once все равно посчитает, что инициализация завершилась, и установит флаг done = 1. Повторные вызовы Do() выполнять функцию больше не будут!

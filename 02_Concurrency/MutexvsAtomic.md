# Mutex vs Atomic: Когда что применять?

| Критерий          | sync.Mutex                        | sync/atomic                                      |
| ----------------- | --------------------------------- | ------------------------------------------------ |
| Сложность         | Простой в поддержке               | Низкоуровневый                                   |
| Что защищает      | Целые блоки кода / структуры      | Одну числовую переменную или указатель           |
| Накладные расходы | Могут усыплять горутину (gopark)  | "Lock-free (инструкции CPU: LOCK XADD, CMPXCHG)" |
| Скорость          | Медленнее при высокой конкуренции | Максимально быстрая                              |

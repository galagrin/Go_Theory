# Как работает Go Data Race Detector (-race)

В Go встроен один из лучших в индустрии детекторов гонок данных (основан на библиотеке ThreadSanitizer от Google).

### Как запустить?

Достаточно добавить флаг -race при запуске тестов или приложения:

```bash
go run -race main.go
# или при прогоне тестов
go test -race ./...
```

### Как он работает внутри (Under the Hood)?

Race Detector не анализирует статически твой код. Он модифицирует скомпилированный бинарник (вставляет перехватчики на каждую операцию чтения/записи в память) и отслеживает выполнение программы в реальном времени runtime.

-   Векторные часы (Vector Clocks): Runtime ведет историю доступа к ячейкам памяти (какая горутина, когда и с каким типом доступа — READ/WRITE — обращалась к адресу).

-   Отслеживание синхронизаций: Детектор знает обо всех точках синхронизации (закрытие каналов, mutex.Unlock(), wg.Done()).

-   Если детектор видит, что Горутина A записала в адрес 0x00FF, а Горутина B прочитала из адреса 0x00FF без промежуточного события синхронизации — он мгновенно печатает подробнейший стек-трейс с указанием строк кода, где произошел конфликт.

#### Важно знать для собеседования:

Бинарник, собранный с флагом -race, потребляет в 2-10 раз больше памяти и работает в 2-20 раз медленнее. Поэтому -race запускают в CI/CD и при локальном тестировании, но никогда не используют на продакшене.

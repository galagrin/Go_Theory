# Конструкция select

select позволяет горутине ожидать выполнения операций на нескольких каналах одновременно.

-   Если готовы несколько веток case, Go выбирает псевдорандомно одну из них (чтобы предотвратить голодание / starvation других веток).

-   Ветка default делает операцию неблокирующей: если ни один канал не готов, мгновенно выполняется default.

```go
select {
case msg := <-ch1:
    fmt.Println("Получено из ch1:", msg)
case ch2 <- 100:
    fmt.Println("Успешно записано в ch2")
default:
    fmt.Println("Ни один канал не готов, работаем дальше")
}
```

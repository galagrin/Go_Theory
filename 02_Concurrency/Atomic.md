# sync/atomic: Атомарные операции

Пакет `sync/atomic` предоставляет низкоуровневые **примитивы аппаратной синхронизации**, выполняемые прямо на уровне инструкций процессора (без использования мьютексов и контекст-свитчей планировщика).

Атомарные операции **быстрее и легковеснее мьютексов**, но подходят только для простых типов (числа, указатели, булевы флаги).

---

## Основные операции

### 1. Счетчик (`AddInt64`, `AddUint64`)

```go
var counter int64

// Безопасное инкрементирование из 1000 горутин без Mutex!
atomic.AddInt64(&counter, 1)

// Безопасное чтение
val := atomic.LoadInt64(&counter)
```

### 2. Compare-And-Swap (CAS)

Базовый примитив для построения Lock-Free алгоритмов.

Сравнивает текущее значение в памяти с ожидаемым old, и только если они равны — записывает new.

```go
var state int32 // 0 - свободно, 1 - занято

func TryLock() bool {
    // Если state == 0, заменить на 1 и вернуть true
    return atomic.CompareAndSwapInt32(&state, 0, 1)
}
```

## 3. atomic.Value (Для любых сложных типов)

Позволяет атомарно читать и перезаписывать сложные структуры/карты целиком (например, для горячей перезагрузки конфигурации).

```go
var configValue atomic.Value

// Запись нового конфига
configValue.Store(newConfig)

// Чтение текущего конфига
cfg := configValue.Load().(*Config)
```
